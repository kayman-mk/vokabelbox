# Support

For usage questions and product suggestions, open a GitHub issue with enough context to understand the question. Do not post passwords, tokens, private vocabulary data, or other sensitive information.

For suspected security vulnerabilities, use the private process in [SECURITY.md](SECURITY.md), not a public issue.

This repository is in the planning stage. The current scope and known open decisions are documented in [docs/SPECIFICATION.md](docs/SPECIFICATION.md).
