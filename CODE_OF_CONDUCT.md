# Code of Conduct

## Our standard

Everyone participating in the VokabelBox project is expected to make the community welcoming and respectful. Treat others with patience, assume good intent while addressing impact, and focus criticism on ideas and work rather than people.

Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing, intimidation, and sustained disruptive conduct.

## Responsibilities

Project maintainers may edit or remove contributions and may temporarily or permanently restrict participation when needed to keep the project safe and constructive. They will explain moderation decisions when practical.

## Reporting

For conduct concerns, contact the repository owner privately through GitHub rather than posting sensitive details in a public issue. For security vulnerabilities, follow [SECURITY.md](SECURITY.md).
